## 計画中のデータモデル（未実装）

以下は `features.md` / `plan.md` に基づく設計予定のモデルです。

### タイマー状態（フロントエンド）

タイマーは以下の4つの状態を持つ予定です。

| 状態 | 説明 |
|---|---|
| `IDLE` | 初期状態・未開始 |
| `RUNNING` | カウントダウン中 |
| `PAUSED` | 一時停止中 |
| `FINISHED` | タイマー終了 |

### セッション種別（フロントエンド）

| 種別 | 時間 | 説明 |
|---|---|---|
| `WORK` | 25分 | 作業セッション |
| `SHORT_BREAK` | 5分 | 短い休憩 |
| `LONG_BREAK` | 15分 | 長い休憩（4回作業後） |

### 設定（API連携予定）

```json
{
  "work_minutes": 25,
  "short_break_minutes": 5,
  "long_break_minutes": 15
}
```

### 完了セッション記録（API連携予定）

```json
{
  "type": "WORK",
  "completed_at": "2026-04-17T07:00:00Z",
  "duration_seconds": 1500
}
```
